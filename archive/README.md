# Archive

Legacy / one-off artifacts kept for historical reference. Not used by current runtime.

## Layout

- `patches/` — old `patch_*.js` / `patch_*.py` scratch patchers (from menu / webhook iterations).
- `legacy-fixes/` — `fix-*.sh` one-shot repair scripts.
- `backups/` — `*.bak`, `*.bak2`, `*.patch` snapshots of `pt-menu.sh`.

## Policy

- Do **not** add new files here. Use proper PRs / `tools/` / `bin/` instead.
- Safe to delete after 90 days if unreferenced.
